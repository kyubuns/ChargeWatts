# ChargeWatts

Macのメニューバーに、接続中の充電器から受け取れる最大電力を稲妻アイコンと `94W` のような整数で表示します。最大電力にはmacOSが報告する値を使い、小数点以下は切り捨てます。メニューを開くと、現在の入力、最大電力、バッテリーの充電・放電電力を小数第1位まで表示します。アダプタ名と接続時に決まった電圧・電流も確認できます。

## 省電力の方針

バッテリーの消費を抑えることを最優先にします。電力データはIOKitから直接読み取り、更新のたびに別のプロセスを起動しません。

充電器の抜き差しはmacOSの電源変更通知で検知します。接続直後は `…` を表示し、接続から5秒間は約1秒ごと、その後は約10秒ごとに最大電力を読み取ります。充電器を抜くとすぐに表示を消し、定期更新を止めます。電源変更通知を受け取れない環境では、再接続を検知するために約10秒ごとの更新を続けます。実際の入力とバッテリーの電力はメニューを開いたときに読み取ります。

更新方法を変えるときは、給電中とバッテリー駆動中の両方でCPU使用率を確認します。

## ビルドと起動

IOKitから電力データを取得できるAppleシリコン搭載のMacBookが対象です。ビルドにはXcodeコマンドラインツールが必要です。

```sh
./build.sh
open build/ChargeWatts.app
```

macOS 13以降でログイン時に起動するには、アプリを「アプリケーション」フォルダに移し、メニューから「Launch at Login」を選びます。
